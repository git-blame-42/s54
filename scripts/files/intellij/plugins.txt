# MVC próprio + Docker + MySQL). Lido por scripts/12-1-config-intellij.sh.

# Formato: um ID por linha (o <id> do META-INF/plugin.xml; sem <id>,
# o <name>; pode ter espaços). Linhas com "#" no começo são comentários.

# - marketplace: o script roda "<IDE> installPlugins <id>" para cada um;

#   plugin.xml do IDE; se faltar algum, tenta o marketplace.
