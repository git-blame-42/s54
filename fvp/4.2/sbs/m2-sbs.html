1. lib/Validations.php

Método novo logo depois de integerMin (linhas ~78-94), antes do docblock de validDate:

        return true;
    }

    /**
     * O texto deve ter no máximo $max caracteres (conta caracteres, não bytes: "ç" vale 1).
     */
    public static function maxLength($attribute, $obj, int $max)
    {
        $value = $obj->$attribute;

        if (is_scalar($value) && mb_strlen((string) $value) > $max) {
            $obj->addError($attribute, "deve ter no máximo {$max} caracteres!");
            return false;
        }

        return true;
    }

Por quê:

  • lib/Validations.php é a caixa de regras reutilizáveis do framework. Formato fixo: estático ($attribute, $obj, ...), lê $obj->$attribute, chama addError e devolve bool. Copie integerMin.
  • Devolver bool é o que permite encadear com && no model.
  • mb_strlen, não strlen: strlen('ção') = 5 bytes; mb_strlen = 3. Com strlen, título acentuado seria barrado antes dos 100.
  • is_scalar: array atribuído direto ao model não estoura Array to string conversion (o ErrorsHandler vira 500). Pelo form (event[title][]=x) o array nem chega: o fill() do controller já troca valor não escalar por null.
  • Mensagem pt-BR terminada em !, como as demais.
  • int $max tipado: lib/ fica fora do phpstan, mas o phpcs roda.

validates(), primeira linha (linha ~62). Trocar:

por:

        Validations::notEmpty('title', $this) &&

Por quê:

  • Validação mora no model, nunca no controller (recusado na prova). save() chama validates() e só grava sem erros.
  • && = curto-circuito: vazio mostra só "não pode ser vazio!". Mesmo encadeamento de kind, modality, starts_on logo abaixo.
  • 100 literal, como o 1 de integerMin. O VARCHAR(255) do schema fica; a regra de negócio é mais estrita.
  • Controller/view não mudam: o form já mostra $event->errors('title') via $feedback('title').

Armadilhas (resumo)

  • strlen conta bytes: use mb_strlen (acentos).
  • null: notEmpty primeiro, por isso o &&.
  • Mensagem pt-BR terminada em !.
  • Validação no controller: recusada (regra de negócio no model).
  • Model anônimo do teste sem a coluna name: Property name not found. Mantenha o // @phpstan-ignore-line.
  • lib/ fora do phpstan: tipe int $max mesmo assim.
  • integerMax tem caso real: capacity > 2147483647 (INT) passa no integerMin e estoura no INSERT (PDOException, 500).
  • Caso real na base: título/local > 255 caracteres passa no notEmpty e estoura o VARCHAR(255) (MySQL estrito, 500). VARCHAR conta caracteres (mb_strlen); description é TEXT, limite em bytes (strlen).
