Pedido típico: "na listagem, filtre por tipo: /admin/events?kind=workshop; o filtro continua valendo ao trocar de página". A rubrica pede where. Chance: alta. Tempo: 25-35 min.

Exemplo pronto: fvp/4.2/exemplos/n1-filtro-por-tipo-paginacao/ (patch, bundle e árvore projeto/). Implementa a forma 2 do catálogo (com paginação). Pré-requisitos: nenhum (parte de main). Schema não muda.

    /**
     * `?kind=` só vale se for uma das chaves de Event::KINDS; senão, sem filtro.
     */
    private function kindFilter(Request $request): ?string
    {
        $kind = $request->getParam('kind');

        return is_string($kind) && array_key_exists($kind, Event::KINDS) ? $kind : null;
    }

Por quê:
